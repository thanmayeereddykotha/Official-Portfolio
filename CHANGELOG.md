# Changelog

All notable changes to the Thanmayee Reddy Kotha Official Portfolio will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2026-10-23

### Added
- **Interactive 3D Desk Hero**: Localized Spline 3D model with background buffer precompilation and deferred Start trigger.
- **Single-Drop Animation Engine**: Implemented reactive EventManager Proxy to prevent duplicate monitor drops.
- **Luxury Start Loader**: High-contrast white architectural preloader counting from 000% to 100% with synchronized veil transition.
- **Project 04 (Portfolio HQ)**: Real-time crypto asset and portfolio risk intelligence dashboard in widescreen 16:9 format.
- **My Approach Showcase Matrix**: Curated 8-dashboard business intelligence gallery with calibrated 3D coordinates.
- **SEO & Accessibility**: Embedded Schema.org JSON-LD Person graph and full ARIA navigation tags.
- **Developer Documentation**: Added `ARCHITECTURE.md`, `CONTRIBUTING.md`, `.editorconfig`, and `.gitattributes`.

### Fixed
- Intercepted premature `Start.connect()` call during `app.start(buffer)` so the monitor drops strictly once after veil removal.
- WebGPU texture swapchain zero-dimension descriptor validation warnings.
- Responsive mobile positioning for the interactive showcase close action.

### Changed
- Standardized project card aspect ratios: alternating Square (1:1) and Widescreen (16:9).
- Dynamic navigation positioning: top bar during 3D hero mode, floating pill dock on content sections.
